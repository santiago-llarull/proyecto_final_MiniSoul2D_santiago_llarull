
# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),

## [0.1.0] - 2026-08-29

### Añadido
- Creación de la estructura base del proyecto utilizando MonoGame y el SDK de .NET 8.
- Configuración inicial del archivo `.gitignore` para excluir binarios y archivos temporales de Visual Studio.
- Creación del archivo `README.md` con las instrucciones de compilación, ejecución y tecnologías detalladas.
- Publicación del documento de la propuesta formal en la Wiki del repositorio (incluyendo mecánicas, alcance y tecnologías a investigar).
